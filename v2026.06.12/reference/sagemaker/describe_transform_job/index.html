describeTransformJob¶

pub fn describeTransformJob(self: *Self, allocator: std.mem.Allocator, input: describe_transform_job.DescribeTransformJobInput, options: CallOptions) !describe_transform_job.DescribeTransformJobOutput

Returns information about a transform job.

Input: DescribeTransformJobInput¶

transform_job_name¶

Type: []const u8

The name of the transform job that you want to view details of.

Output: DescribeTransformJobOutput¶

auto_ml_job_arn¶

Type: ?[]const u8 (optional)

The Amazon Resource Name (ARN) of the AutoML transform job.

batch_strategy¶

Type: ?BatchStrategy (optional)

Specifies the number of records to include in a mini-batch for an HTTP inference request. A record is a single unit of input data that inference can be made on. For example, a single line in a CSV file is a record.

To enable the batch strategy, you must set SplitType to Line, RecordIO, or TFRecord.

creation_time¶

Type: i64

A timestamp that shows when the transform Job was created.

data_capture_config¶

Type: ?BatchDataCaptureConfig (optional)

Configuration to control how SageMaker captures inference data.

data_processing¶

Type: ?DataProcessing (optional)

environment¶

Type: ?[]const aws.map.StringMapEntry (optional)

The environment variables to set in the Docker container. We support up to 16 key and values entries in the map.

experiment_config¶

Type: ?ExperimentConfig (optional)

failure_reason¶

Type: ?[]const u8 (optional)

If the transform job failed, FailureReason describes why it failed. A transform job creates a log file, which includes error messages, and stores it as an Amazon S3 object. For more information, see Log Amazon SageMaker Events with Amazon CloudWatch.

labeling_job_arn¶

Type: ?[]const u8 (optional)

The Amazon Resource Name (ARN) of the Amazon SageMaker Ground Truth labeling job that created the transform or training job.

max_concurrent_transforms¶

Type: ?i32 (optional)

The maximum number of parallel requests on each instance node that can be launched in a transform job. The default value is 1.

max_payload_in_mb¶

Type: ?i32 (optional)

The maximum payload size, in MB, used in the transform job.

model_client_config¶

Type: ?ModelClientConfig (optional)

The timeout and maximum number of retries for processing a transform job invocation.

model_name¶

Type: []const u8

The name of the model used in the transform job.

transform_end_time¶

Type: ?i64 (optional)

Indicates when the transform job has been completed, or has stopped or failed. You are billed for the time interval between this time and the value of TransformStartTime.

transform_input¶

Type: ?TransformInput (optional)

Describes the dataset to be transformed and the Amazon S3 location where it is stored.

transform_job_arn¶

Type: []const u8

The Amazon Resource Name (ARN) of the transform job.

transform_job_name¶

Type: []const u8

The name of the transform job.

transform_job_status¶

Type: TransformJobStatus

The status of the transform job. If the transform job failed, the reason is returned in the FailureReason field.

transform_output¶

Type: ?TransformOutput (optional)

Identifies the Amazon S3 location where you want Amazon SageMaker to save the results from the transform job.

transform_resources¶

Type: ?TransformResources (optional)

Describes the resources, including ML instance types and ML instance count, to use for the transform job.

transform_start_time¶

Type: ?i64 (optional)

Indicates when the transform job starts on ML instances. You are billed for the time interval between this time and the value of TransformEndTime.
