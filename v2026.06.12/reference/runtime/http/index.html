http¶

HTTP utilities for AWS requests

Wrapper around std.http.Client with retry support and connection pooling.

RequestOptions¶

HTTP request options

max_attempts¶

Type: ?u32 (optional)

Maximum retry attempts (null = use HttpClient.default_max_attempts)

base_delay_ms¶

Type: ?u32 (optional)

Base delay for exponential backoff in ms (null = use HttpClient.default_base_delay_ms)

max_delay_ms¶

Type: u32

Maximum delay cap in milliseconds (default: 20 seconds)

max_response_size¶

Type: usize

Maximum response body size (default: 10MB)

keep_alive¶

Type: bool

HTTP connection keep-alive (default: true). Set to false when the server may omit Content-Length on responses, which would otherwise cause reads to block until the server's keep-alive timeout.

Type: std.ArrayList([]const u8)

Header values whose memory is owned by this Request and must be freed in deinit. signRequest and similar callers that allocPrint or dupe values into headers register them here so the Request is safe to use without an arena.

generateUuidV4¶

pub fn generateUuidV4(io: std.Io, buf: *[36]u8) void

Generate a UUID v4 string into buf. Version bits are set to 0100 and variant bits to 10xx per RFC 4122.

statusForbidsBody¶

pub fn statusForbidsBody(status: std.http.Status) bool

True if the HTTP status code disallows a response body per RFC 9110 6.4.1: 1xx Informational, 204 No Content, 304 Not Modified.

shouldBypassProxy¶

pub fn shouldBypassProxy(
    host: []const u8,
    no_proxy_entries: []const []const u8,
    no_proxy_wildcard: bool,
) bool

Check if a host should bypass the proxy based on the NO_PROXY list.

Entries are comma-separated. Matching rules: - "*" bypasses all hosts - Exact match (case-insensitive) - Domain suffix: ".example.com" matches "api.example.com"
