Reader¶

Streaming XML event parser operating on a complete []const u8 buffer. No allocations required for the reader itself -- returned slices borrow from the source buffer.

readElementText¶

pub fn readElementText(self: *Reader) Error![]const u8

After receiving .element_start, reads text content up to the matching </tag> and returns a borrowed slice. Consumes the end tag. Skips any child elements encountered before text.

skipElement¶

pub fn skipElement(self: *Reader) Error!void

After receiving .element_start, skips the entire element including all children until the matching </tag>.

findElement¶

pub fn findElement(xml: []const u8, tag_name: []const u8) ?[]const u8

Simple string-search XML element finder. Searches for <tag_name> or <tag_name ...> (with attributes) and returns the text content up to the matching </tag_name>, or null if not found. Used for error response parsing where a full XML parse is not needed.

Append a value to a buffer with XML entity escaping for &, <, and >.

unescapeXml¶

pub fn unescapeXml(allocator: std.mem.Allocator, source: []const u8) ![]const u8

Decode XML entity references (& < > " ' &#NNN; &#xHH;) into an owned string. Returns a copy of the input if no entities were found, materializing a decoded copy when needed.
