getStage¶

pub fn getStage(self: *Self, allocator: std.mem.Allocator, input: get_stage.GetStageInput, options: CallOptions) !get_stage.GetStageOutput

Gets a Stage.

Input: GetStageInput¶

api_id¶

Type: []const u8

The API identifier.

stage_name¶

Type: []const u8

The stage name. Stage names can only contain alphanumeric characters, hyphens, and underscores. Maximum length is 128 characters.

Output: GetStageOutput¶

access_log_settings¶

Type: ?AccessLogSettings (optional)

Settings for logging access in this stage.

api_gateway_managed¶

Type: ?bool (optional)

Specifies whether a stage is managed by API Gateway. If you created an API using quick create, the $default stage is managed by API Gateway. You can't modify the $default stage.

auto_deploy¶

Type: ?bool (optional)

Specifies whether updates to an API automatically trigger a new deployment. The default value is false.

client_certificate_id¶

Type: ?[]const u8 (optional)

The identifier of a client certificate for a Stage. Supported only for WebSocket APIs.

created_date¶

Type: ?i64 (optional)

The timestamp when the stage was created.

default_route_settings¶

Type: ?RouteSettings (optional)

Default route settings for the stage.

deployment_id¶

Type: ?[]const u8 (optional)

The identifier of the Deployment that the Stage is associated with. Can't be updated if autoDeploy is enabled.

description¶

Type: ?[]const u8 (optional)

The description of the stage.

last_deployment_status_message¶

Type: ?[]const u8 (optional)

Describes the status of the last deployment of a stage. Supported only for stages with autoDeploy enabled.

last_updated_date¶

Type: ?i64 (optional)

The timestamp when the stage was last updated.

route_settings¶

Type: ?[]const aws.map.MapEntry(RouteSettings) (optional)

Route settings for the stage, by routeKey.

stage_name¶

Type: ?[]const u8 (optional)

The name of the stage.

stage_variables¶

Type: ?[]const aws.map.StringMapEntry (optional)

A map that defines the stage variables for a stage resource. Variable names can have alphanumeric and underscore characters, and the values must match [A-Za-z0-9-._~:/?#&=,]+.

tags¶

Type: ?[]const aws.map.StringMapEntry (optional)

The collection of tags. Each tag element is associated with a given resource.
