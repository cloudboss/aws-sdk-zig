updateFunction¶

pub fn updateFunction(self: *Self, allocator: std.mem.Allocator, input: update_function.UpdateFunctionInput, options: CallOptions) !update_function.UpdateFunctionOutput

Updates a Function object.

Input: UpdateFunctionInput¶

api_id¶

Type: []const u8

The GraphQL API ID.

code¶

Type: ?[]const u8 (optional)

The function code that contains the request and response functions. When code is used, the runtime is required. The runtime value must be APPSYNC_JS.

data_source_name¶

Type: []const u8

The Function DataSource name.

description¶

Type: ?[]const u8 (optional)

The Function description.

function_id¶

Type: []const u8

The function ID.

function_version¶

Type: ?[]const u8 (optional)

The version of the request mapping template. Currently, the supported value is 2018-05-29. Note that when using VTL and mapping templates, the functionVersion is required.

max_batch_size¶

Type: ?i32 (optional)

The maximum batching size for a resolver.

name¶

Type: []const u8

The Function name.

request_mapping_template¶

Type: ?[]const u8 (optional)

The Function request mapping template. Functions support only the 2018-05-29 version of the request mapping template.

response_mapping_template¶

Type: ?[]const u8 (optional)

The Function request mapping template.

runtime¶

Type: ?AppSyncRuntime (optional)

sync_config¶

Type: ?SyncConfig (optional)

Output: UpdateFunctionOutput¶

function_configuration¶

Type: ?FunctionConfiguration (optional)

The Function object.
