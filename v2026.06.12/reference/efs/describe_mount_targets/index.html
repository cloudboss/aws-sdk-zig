describeMountTargets¶

pub fn describeMountTargets(self: *Self, allocator: std.mem.Allocator, input: describe_mount_targets.DescribeMountTargetsInput, options: CallOptions) !describe_mount_targets.DescribeMountTargetsOutput

Returns the descriptions of all the current mount targets, or a specific mount target, for a file system. When requesting all of the current mount targets, the order of mount targets returned in the response is unspecified.

This operation requires permissions for the elasticfilesystem:DescribeMountTargets action, on either the file system ID that you specify in FileSystemId, or on the file system of the mount target that you specify in MountTargetId.

Input: DescribeMountTargetsInput¶

access_point_id¶

Type: ?[]const u8 (optional)

(Optional) The ID of the access point whose mount targets that you want to list. It must be included in your request if a FileSystemId or MountTargetId is not included in your request. Accepts either an access point ID or ARN as input.

file_system_id¶

Type: ?[]const u8 (optional)

(Optional) ID of the file system whose mount targets you want to list (String). It must be included in your request if an AccessPointId or MountTargetId is not included. Accepts either a file system ID or ARN as input.

marker¶

Type: ?[]const u8 (optional)

(Optional) Opaque pagination token returned from a previous DescribeMountTargets operation (String). If present, it specifies to continue the list from where the previous returning call left off.

max_items¶

Type: ?i32 (optional)

(Optional) Maximum number of mount targets to return in the response. Currently, this number is automatically set to 10, and other values are ignored. The response is paginated at 100 per page if you have more than 100 mount targets.

mount_target_id¶

Type: ?[]const u8 (optional)

(Optional) ID of the mount target that you want to have described (String). It must be included in your request if FileSystemId is not included. Accepts either a mount target ID or ARN as input.

Output: DescribeMountTargetsOutput¶

marker¶

Type: ?[]const u8 (optional)

If the request included the Marker, the response returns that value in this field.

mount_targets¶

Type: ?[]const MountTargetDescription (optional)

Returns the file system's mount targets as an array of MountTargetDescription objects.

next_marker¶

Type: ?[]const u8 (optional)

If a value is present, there are more mount targets to return. In a subsequent request, you can provide Marker in your request with this value to retrieve the next set of mount targets.
