updateDataRepositoryAssociation¶

pub fn updateDataRepositoryAssociation(self: *Self, allocator: std.mem.Allocator, input: update_data_repository_association.UpdateDataRepositoryAssociationInput, options: CallOptions) !update_data_repository_association.UpdateDataRepositoryAssociationOutput

Updates the configuration of an existing data repository association on an Amazon FSx for Lustre file system. Data repository associations are supported on all FSx for Lustre 2.12 and 2.15 file systems, excluding scratch_1 deployment type.

Input: UpdateDataRepositoryAssociationInput¶

association_id¶

Type: []const u8

The ID of the data repository association that you are updating.

client_request_token¶

Type: ?[]const u8 (optional)

imported_file_chunk_size¶

Type: ?i32 (optional)

For files imported from a data repository, this value determines the stripe count and maximum amount of data per file (in MiB) stored on a single physical disk. The maximum number of disks that a single file can be striped across is limited by the total number of disks that make up the file system.

The default chunk size is 1,024 MiB (1 GiB) and can go as high as 512,000 MiB (500 GiB). Amazon S3 objects have a maximum size of 5 TB.

s3¶

Type: ?S3DataRepositoryConfiguration (optional)

The configuration for an Amazon S3 data repository linked to an Amazon FSx Lustre file system with a data repository association. The configuration defines which file events (new, changed, or deleted files or directories) are automatically imported from the linked data repository to the file system or automatically exported from the file system to the data repository.

Output: UpdateDataRepositoryAssociationOutput¶

association¶

Type: ?DataRepositoryAssociation (optional)

The response object returned after the data repository association is updated.
